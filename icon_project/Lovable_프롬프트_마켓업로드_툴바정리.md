# Lovable 프롬프트 — 아이콘/배경 보관함 툴바 정리 + 마켓 업로드 옵션 통합

>   응답에 `url` 필드 추가). 프론트의 `srcOf(a)=localEngineUrl(a.url)`가 이제 정상 동작합니다. 이 부분은 건드리지 마세요.

보관함(`src/pages/Library.tsx` + `src/components/presets/WallpaperLibrary.tsx`)의 아이콘·배경화면 탭을 아래처럼 정리해줘.

## A) 배경화면 탭 (`WallpaperLibrary.tsx`)
1. **우측 상단의 "마켓에서 찾기" 버튼과 "배경화면 추가" 버튼을 삭제**해줘. (두 기능은 아래 생성 모달로 이동)
2. "새 배경화면 만들기" 카드 클릭 시 뜨는 `CreateOption` 모달에 **선택지 3개**로 구성:
   - **마켓에서 불러오기** (icon `Store`) → `nav("/explore")` (기존 "마켓에서 찾기" 역할)
   - **로컬 가져오기** (icon `Upload`) → 기존 파일 업로드 흐름(`uploadWallpaper` → `POST /api/wallpaper/upload` → 목록 새로고침) (기존 "배경화면 추가" 역할)
   - **마켓에 업로드** (icon `Store` 또는 `UploadCloud`) → **배경화면을 마켓에 게시하는 모달**(`MarketWallpaperUploadModal`)을 연다. 카드 선택 없이도 열리도록, 이미지 선택/업로드 + 이름·설명·태그·공개여부 입력 폼을 제공(아이콘의 `MarketIconUploadModal` 양식과 동일한 형태). 즉 보관함 배경 중 하나를 고르거나 새 이미지를 올려서 게시.
3. 부제 텍스트는 `마켓 · 로컬 가져오기 · 마켓에 업로드` 로.

## B) 아이콘 탭 (`Library.tsx` 아이콘 탭)
1. **툴바 재배치**: 현재 `[아이콘 이름 검색] ...... [최신순][묶기][마켓에 올리기]` 로 흩어져 있는데,
   **"최신순" 정렬 드롭다운과 "묶기" 버튼을 검색창 바로 오른쪽에 붙여서** 한 그룹으로 만들어줘.
   → 결과: `[아이콘 이름 검색][최신순][묶기]` 가 한 줄에 인접.
2. **우측 상단의 "마켓에 올리기" 버튼을 삭제**해줘. (기능은 아래 생성 모달로 이동)
3. "새 아이콘 만들기" 카드 모달(`CreateOption`)에 **선택지 3개**로 구성:
   - **마켓에서 불러오기** (icon `Store`) → `nav("/explore")`
   - **로컬 가져오기** (icon `Upload`) → 기존 아이콘 파일 업로드 흐름(`POST /api/icons/upload`, 다중 선택)
   - **마켓에 업로드** (icon `Store`/`UploadCloud`) → 기존 아이콘 마켓 게시 모달(`MarketIconUploadModal`, "마켓에 올리기"가 열던 그 모달)을 그대로 연다.
4. 부제 텍스트는 `마켓 · 로컬 가져오기 · 마켓에 업로드` 로.

## C) 일관성
- 세 탭(프리셋/아이콘/배경) 모두 동일한 점선 생성 카드 + 공용 `CreateOption` 모달 스타일 유지.
- "마켓에 업로드" 선택지는 아이콘·배경 둘 다 **아이콘 마켓 업로드 양식과 동일한 UX**(이미지 미리보기 + 이름/설명/태그/공개여부 → 게시).
- 기존 업로드/게시 로직·엔드포인트는 재사용하고 **진입점만 이동**. 새 백엔드 호출 추가 금지.
- 배경 게시는 한 장씩(단일). `.env`는 건드리지 말 것.
