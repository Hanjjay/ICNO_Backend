# Lovable 프롬프트 — 보관함 '새로 만들기' 형식 통일 (프리셋 → 아이콘/배경)

> 아래 블록 전체를 복사해서 Lovable에 붙여넣으세요. 프론트엔드 전용 변경입니다.

---

보관함(`src/pages/Library.tsx`)에서 프리셋 탭에 있는 "새 프리셋 만들기" 카드 + 모달 형식을,
**아이콘 탭과 배경화면 탭에도 동일하게** 적용해줘. 요구사항은 정확히 아래와 같아.

## 1) 프리셋 탭 — 문구만 수정
- "새 프리셋 만들기" 카드의 부제 텍스트 `빈 프리셋 · 마켓 · 로컬 가져오기` 에서 **"· 로컬 가져오기"를 제거**해서
  `빈 프리셋 · 마켓` 로 바꿔줘. (모달 옵션은 지금처럼 "빈 프리셋 만들기" + "마켓에서 불러오기" 그대로 유지.)

## 2) 아이콘 탭 — "새 아이콘 만들기" 카드 + 모달 추가
- 아이콘 그리드의 **맨 앞에** 프리셋과 동일한 점선(dashed) 생성 카드를 추가:
  - 아이콘: `Plus`
  - 제목: **새 아이콘 만들기**
  - 부제: **마켓 · 로컬 가져오기**
- 클릭하면 프리셋 `createOpen` 모달과 똑같은 스타일의 `Dialog`(같은 `CreateOption` 컴포넌트 재사용)를 열고, **옵션 2개**만:
  1. **마켓에서 불러오기** — icon `Store`, 설명 "마켓플레이스에서 아이콘을 다운로드", onClick → `nav("/explore")`
  2. **로컬 가져오기** — icon `Upload`, 설명 "내 컴퓨터에서 이미지 파일을 올리기", onClick → **기존 아이콘 업로드 흐름 실행**(현재 아이콘 탭이 쓰는 파일 선택 → `POST /api/icons/upload` → 보관함 반영). 다중 선택 허용.
- ※ 아이콘에는 "빈 아이콘" 같은 옵션은 없음. 마켓/로컬 두 개만.

## 3) 배경화면 탭 — "새 배경화면 만들기" 카드 + 모달 추가
- 배경화면 그리드(`WallpaperLibrary` 등) **맨 앞에** 동일한 점선 생성 카드 추가:
  - 아이콘: `Plus`
  - 제목: **새 배경화면 만들기**
  - 부제: **마켓 · 로컬 가져오기**
- 클릭 시 동일한 `Dialog` + `CreateOption` 모달, 옵션 2개:
  1. **마켓에서 불러오기** — icon `Store`, 설명 "마켓플레이스에서 배경화면을 다운로드", onClick → `nav("/explore")`
  2. **로컬 가져오기** — icon `Upload`, 설명 "내 컴퓨터에서 이미지 파일을 올리기", onClick → **기존 배경 업로드 흐름 실행**(`POST /api/wallpaper/upload` → `GET /api/wallpapers/library` 새로고침). 배경은 한 장씩.

## 4) 일관성 규칙
- 세 탭 모두 **동일한 생성 카드 디자인**(점선 border, `min-h`, `Plus` 아이콘, 제목/부제 2줄)과 **동일한 모달 레이아웃**(프리셋의 `CreateOption` 재사용, `grid grid-cols-2 gap-3`)을 사용해 시각적으로 통일할 것.
- 각 모달 제목/설명만 대상에 맞게: "새 아이콘 만들기 / 어떻게 시작할지 선택하세요", "새 배경화면 만들기 / 어떻게 시작할지 선택하세요".
- 기존 업로드 로직/엔드포인트는 그대로 재사용하고 **UI 진입점만 이 형식으로 통일**해줘. 새 백엔드 호출 추가 금지.
- `.env`는 건드리지 말 것.
